    moneda: "Arcade game jump coin", caja: "Arcade video game pop", ruleta: "Video game retro click",
    poder: "Unlock new item game notification", banana: "Funny video game slide", tirar banana: "Funny cartoon fast splat",
    explosión: "Arcade game explosion", baranda: "Small hit in a game", turbo: "Speeding swoosh",
    mini-turbo: "Fast whoosh transition", misil: "Fast rocket whoosh", chispas: "Fairy arcade sparkle",
    vuelta: "Game bonus reached", llegada: "Game level completed".
